# Asteroids

Package `rocks`, version 1.0.0. Native port of `apps/rocks/rocks.c` using
ABI2, the original 40 ms clock, wrapped outlines and module-local libm/libgcc.

MENU +/- turn, A thrusts, B fires, and the optional knob sets heading. A+B must
remain thrust+fire; hold both top MENU buttons for the OS Home restart.
`check.py` compares the original model/pixels. See the parent README for builds.
