# Hackaday

Package `hackaday`, version 1.0.0. Native reader retains the original feed/parser,
article layout, font, paging, Retry/Refresh/Back and six-scene wipe behavior.
Layout is bounded to 4000 retained lines and examines at most cols+1 bytes per line.

The frozen Hackaday ABI extension delegates bounded HTTP/media jobs to the host.
B goes back; hold A+B for 600 ms to exit. See the parent README for builds.
Repository GPL-2.0 and original Hackaday attribution apply.
