# Video

Package `video`, version 1.0.0. Native port of `apps/video/video.c` and its VID2
player using the frozen Video ABI extension. A restarts; B returns Home.

The unsigned ELF and separately signed 819646-byte clip are independent assets.
Clip SHA256: `c804c2cbb5df2830f17a814d65be2fab229b0825d6e89d089a64551d5d6d6df7`.
