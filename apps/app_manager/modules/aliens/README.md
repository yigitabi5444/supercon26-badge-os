# SpaceInv

Package `aliens`, version 1.0.2. Native port of `apps/aliens/aliens.c` using
ABI2, the original 50 ms model clock and leased host rendering.

A/B move left/right; MENU + or MENU - fires. The optional knob also steers.
Hold A+B for 600 ms to exit.
`run_model_tests.py` and `run_native_tests.py` compare the original model/pixels;
`build.py` emits the unsigned package. See the parent README for build commands.
