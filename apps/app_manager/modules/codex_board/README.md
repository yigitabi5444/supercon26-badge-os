# Codex Board

Package `codex_board`, version 1.0.0. Parser, USB framer, alert history and native
view derived from `apps/codex_board` (ml-sudocode, PR #5).

The frozen Codex ABI extension delegates USB/LAN transport, saved endpoint/seen
state, LEDs and frame leases to the host. The module imports only the API getter.
See the parent README for builds. Repository license and attribution apply.
